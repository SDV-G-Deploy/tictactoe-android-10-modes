# Крестики-нолики (Android, 10 режимов)

Офлайн-приложение на Kotlin с 10 игровыми режимами в одном APK.

## Что нового в v1.2.0

### UI/UX поля (все режимы)
- Полностью обновлён экран игры на **Jetpack Compose**.
- Игровое поле теперь аккуратно масштабируется под разные экраны.
- Улучшены отступы, контраст, читаемость и размер X/O.
- Добавлена заметная индикация: текущий ход, победитель, ничья.
- Обновлены карточки режима и кнопки действий в современном стиле Material 3.

### Ultimate (9x9)
- Визуально выделены 9 мини-полей 3x3 (утолщённые границы блоков).
- Добавлена подсветка активного мини-поля (куда обязан ходить игрок).
- Неактивные зоны приглушаются, но остаются читаемыми.
- Улучшены тап-зоны клеток и общий масштаб поля, режим стал играбельным на телефоне.
- Сохранена и проверена логика ограничений хода: разрешены только допустимые мини-поля.

### Тесты
- Добавлены unit-тесты для базовых правил Ultimate:
  - направление следующего хода в нужный мини-блок;
  - запрет хода вне обязательного блока;
  - проверка, что разрешённые ходы всегда соответствуют allowed mini-boards.

## Режимы

1. Классика 3x3
2. 4x4 (4 в ряд)
3. 5x5 (4 в ряд)
4. 5x5 (5 в ряд)
5. Misère 3x3
6. Ultimate 9x9
7. Random Blocked Cells
8. Timed Turn
9. Bomb Cell
10. Gravity Mode

## Архитектура (ключевые файлы)

- `app/src/main/java/com/example/tictactoe/MainActivity.kt` — Compose UI (меню, экран игры, отрисовка поля).
- `app/src/main/java/com/example/tictactoe/GameModes.kt` — игровая логика и правила всех режимов.
- `app/src/test/java/com/example/tictactoe/UltimateModeTest.kt` — unit-тесты Ultimate-логики.

## Сборка

### Требования
- JDK 17+
- Android SDK

### Debug
```bash
./gradlew assembleDebug
```
APK:
`app/build/outputs/apk/debug/app-debug.apk`

### Тесты
```bash
./gradlew testDebugUnitTest
```
